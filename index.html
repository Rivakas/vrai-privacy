Lietuvių kalba

Kokius duomenis apdoroja programos

Programos apdoroja tik funkcijoms reikalingus duomenis:

  • Garsas ir tekstas. VrAI Pass įrašo jūsų paspaudimu pradėtą klausimą ir siunčia garsą transkripcijai; pagal nustatytą funkciją garso ar teksto užklausos siunčiamos „Google Gemini“, „OpenAI“ arba „Anthropic“. VrAI Virt naudoja mikrofoną pokalbiui ar vertimui. Pasirinkus „Qwen“ garso vertėją, garso srautas siunčiamas tiesiai į „Alibaba Cloud Model Studio“ Singapūro regiono API. Įjungus garso vertėją ir atskirai patvirtinus sistemos langą, „VrAI Virt“ gali skaityti kitos programos atkuriamą garsą. Šio garso vertėjas gauna garsą, ne kitos programos vaizdą.
  • Vaizdai. VrAI Pass gali apdoroti passthrough kameros kadrą ir į jį įtrauktą virtualų vaizdą; taip pat gali perskaityti neseniai jūsų akiniuose padarytą sistemos ekrano nuotrauką. VrAI Virt, tik jūsų pasirinktu režimu ir patvirtinus Horizon OS leidimą, gali siųsti ekrano kadrus iš „MediaProjection“. Ji taip pat gali perskaityti jūsų sistemos ekrano nuotrauką. Šie vaizdai siunčiami į tuo metu naudojamo AI tiekėjo paslaugą.
  • AI įvestys ir atsakymai. Klausimai, transkripcijos, vertimo tekstas, vaizdai ir AI atsakymai gali būti trumpam laikomi programos atmintyje, kol vykdoma sesija. Programos neturi leidėjo valdomos pokalbių paskyros ar serverio pokalbių istorijos.
  • API raktai ir nustatymai. Jūsų įvesti API raktai ir nustatymai laikomi atitinkamos programos įrenginio saugykloje. „VrAI Pass“ gali saugoti savo raktus ir veikti be „VrAI Virt“. Jei įdiegtos abi programos, Pass gali gauti raktus iš Virt per Android parašu apsaugotą vietinę sąsają. Programos gali vietoje apsikeisti naujesniais patikrintais modelių vardais ir patikros datomis; raktai su modelių sąrašais neperduodami. Raktai siunčiami tik pasirinktam AI tiekėjui autentifikuoti, o ne programos leidėjui. Jei raktą importuojate per Wi-Fi, įrenginys laikinai priima failą tame pačiame tinkle; šis perdavimas nešifruojamas, todėl naudokite tik patikimą privatų tinklą.
  • Diagnostika. Programos įrenginyje sukuria ribotą techninį žurnalą, iki 500 eilučių, kuris paleidus programą iš naujo pradedamas iš naujo. Diagnostikos įrašuose gali būti klausimo ar eksperto užklausos tekstas; „VrAI Virt“ taip pat gali įrašyti atpažintą pokalbio tekstą ir AI atsakymo tekstą. Įrašoma ir klaidų bei modelio informacija. Raktų reikšmės į žurnalą nerašomos. Žurnalai nėra automatiškai siunčiami leidėjui.
  • Nuotraukos galerijoje. Kai funkcija išsaugo vaizdą, programos naudoja bendrą Quest galeriją ir perrašo savo ankstesnį failą: Pictures/VrAI/VrAI_Pass.jpg arba Pictures/VrAI/VrAI_Virt.jpg. Šie failai lieka galerijoje net išvalius programos privačius duomenis; juos ištrinkite galerijoje.
  • Tinklo techniniai duomenys. Tiesiogiai su AI tiekėju bendraujantis įrenginys atskleidžia jam įprastus ryšio duomenis, pavyzdžiui, IP adresą, API paskyros identifikatorius, užklausų apimtį ir klaidų informaciją. Programos taip pat gali tiesiogiai kreiptis į AI tiekėjų modelių katalogus, kai naudotojas prašo atnaujinti modelių sąrašą.

Kam naudojami duomenys ir kam jie perduodami

Duomenys apdorojami tik tam, kad veiktų pasirinktas pokalbio, vaizdo supratimo, kalbos atpažinimo, vertimo, balso sintezės ar eksperto atsakymo režimas. Pagal pasirinktą modelį ir funkciją užklausos siunčiamos tiesiai iš įrenginio į „Google“ Gemini API, „OpenAI“ API, „Anthropic“ API arba pasirinkus „Qwen“ garso vertėją – į „Alibaba Cloud Model Studio“ API. Leidėjas neturi tarpinio serverio, kuris priimtų programos garso, vaizdų ar pokalbių turinį.

Šiuos tiekėjus ir jų sąlygas valdo atitinkami tiekėjai: Google Gemini API sąlygos ir duomenų tvarkymas, OpenAI API duomenų valdikliai, Anthropic API duomenų saugojimas, Alibaba Cloud Model Studio privatumas. Tiekėjų saugojimo, peržiūros ir naudojimo taisyklės priklauso nuo jų paslaugos, paskyros, atsiskaitymo būsenos ir įjungtų funkcijų; jos gali keistis. Prieš siųsdami jautrų turinį, perskaitykite tiekėjo sąlygas. AI paslaugos gali būti mokamos pagal jūsų API paskyrą.

Programos nenaudoja leidėjo valdomo debesies pokalbiams saugoti. Leidėjas negauna raktų, klausimų, vaizdų ar garso per programos serverį. Pasirinktas AI tiekėjas gauna tik pasirinktai funkcijai reikalingas užklausas ir ryšio metaduomenis.

Data the apps process

The apps process data needed for the feature you choose:

  • Audio and text. VrAI Pass records a question you start with the control and sends the audio for transcription; depending on the selected feature, audio or text requests go to Google Gemini, OpenAI, or Anthropic. VrAI Virt uses the microphone for conversation or translation. When you select the Qwen audio interpreter, audio is sent directly to the Alibaba Cloud Model Studio Singapore API. When you enable the audio interpreter and approve the system prompt, VrAI Virt can capture audio played by another app. The audio interpreter receives audio, not that app's video.
  • Images. VrAI Pass can process a passthrough camera frame with the virtual view composited into it, and can read a recent system screenshot you took on the headset. VrAI Virt can, only in a mode you choose and after Horizon OS permission, send display frames captured through MediaProjection. It can also read your system screenshots. These images are sent to the AI provider used for that feature.
  • AI inputs and outputs. Questions, transcriptions, translation text, images, and AI responses may be held temporarily in app memory while a session runs. The apps do not provide a publisher-operated chat account or server-side conversation history.
  • API keys and settings. API keys and settings you enter are stored on the headset by the relevant app. VrAI Pass can store its own keys and work without VrAI Virt. If both are installed, Pass can obtain keys from Virt through an Android signature-protected local interface. The apps can locally exchange newer verified model names and check dates; keys are not sent with model lists. Keys are sent only to the selected AI provider for authentication, not to the publisher. If you import a key over Wi-Fi, the headset temporarily accepts a file on the same network; the transfer is not encrypted, so use a trusted private network only.
  • Diagnostics. The apps create a limited on-device technical log of up to 500 lines, reset when the app starts again. Diagnostic entries may include question or expert-request text; VrAI Virt may also log recognized conversation text and AI response text. Error and model information is also logged. Key values are not written to the log. Logs are not automatically sent to the publisher.
  • Gallery images. When image saving is enabled, the apps use the shared Quest gallery and overwrite their own previous file: Pictures/VrAI/VrAI_Pass.jpg or Pictures/VrAI/VrAI_Virt.jpg. These files remain in the gallery after clearing private app data; delete them separately in the gallery.
  • Network data. The device communicates directly with the AI provider and reveals ordinary connection data such as IP address, API account identifiers, request volume, and error information. The apps may also contact AI-provider model catalogs directly when you request a model-list refresh.

Purposes and recipients

Data is processed only to provide the selected conversation, image understanding, speech recognition, translation, speech generation, or expert-answer feature. Depending on your selected model and feature, requests are sent directly from the headset to Google Gemini API, OpenAI API, Anthropic API, or, for Qwen audio interpretation, Alibaba Cloud Model Studio API. The publisher does not operate an intermediary server that receives app audio, images, or conversation content.

Those providers control their own services and terms: Google Gemini API terms and data handling, OpenAI API data controls, and Anthropic API data retention, and Alibaba Cloud Model Studio privacy. Provider retention, review, and use rules depend on the provider's service, account, billing status, and enabled features, and may change. Review the provider terms before sending sensitive content. AI usage may incur charges on your API account.

The apps do not use a publisher-operated cloud to store conversations. The publisher does not receive keys, questions, images, or audio through an app server. The selected AI provider receives only requests needed for the selected feature and connection metadata.

Storage and deletion

  • Private app settings, keys, and diagnostic files are stored on the Quest device. Clear the app's data or uninstall the relevant app through Quest system app settings to remove its private data. Clearing an app's data also removes API keys stored in that app; make a secure copy first if you still need them.
  • Images saved in the gallery must be deleted separately in the Quest gallery.
  • To ask the publisher to delete data associated with you or to exercise privacy rights, email rivakas@gmail.com. Identify the app and the action requested; do not email API keys, audio, or images. The publisher does not have a server-side copy of conversation content, so use the device steps above to remove local data. Contact the provider through your account or its privacy channel about data held by that provider.

Permissions and your choices

Microphone, passthrough camera, image reading, and screen capture are used only for their respective features. You can stop a feature by turning it off, revoking its permission, or declining the Horizon OS screen-capture prompt. The audio interpreter requires system approval. Start audio or screen capture only when you have the right to process the content shown or heard and have informed other people where required by law.

Changes and contact

This notice will be updated if the apps' data flows change. The current version is published on this public page, whose URL will be listed on both apps' Meta Horizon Store pages. Privacy contact: rivakas@gmail.com.

Какие данные обрабатывают приложения

Приложения обрабатывают данные, необходимые для выбранной функции:

  • Аудио и текст. VrAI Pass записывает вопрос, который вы запускаете кнопкой, и отправляет аудио на распознавание речи; в зависимости от функции аудио или текстовые запросы передаются Google Gemini, OpenAI или Anthropic. VrAI Virt использует микрофон для разговора или перевода. При выборе аудиопереводчика Qwen звук передаётся напрямую в API Alibaba Cloud Model Studio региона Сингапур. Если включить аудиопереводчик и подтвердить системный запрос, VrAI Virt может захватывать звук, воспроизводимый другим приложением. Аудиопереводчик получает звук, а не изображение другого приложения.
  • Изображения. VrAI Pass может обрабатывать кадр камеры passthrough с наложенным виртуальным изображением, а также читать недавний системный снимок экрана, сделанный вами на гарнитуре. VrAI Virt может отправлять кадры экрана через MediaProjection только в выбранном вами режиме и после разрешения Horizon OS. Приложение также может читать ваши системные снимки экрана. Эти изображения отправляются AI-провайдеру, используемому для функции.
  • Ввод и ответы AI. Вопросы, расшифровки речи, текст перевода, изображения и ответы AI могут временно находиться в памяти приложения во время сеанса. Приложения не предоставляют учетную запись чата издателя или серверную историю переписки.
  • API-ключи и настройки. Введенные вами API-ключи и настройки хранятся на гарнитуре в соответствующем приложении. VrAI Pass может хранить свои ключи и работать без VrAI Virt. Если установлены оба приложения, Pass может получать ключи из Virt через локальный интерфейс Android, защищенный подписью. Приложения могут локально обмениваться более новыми проверенными названиями моделей и датами проверки; ключи вместе со списками моделей не передаются. Ключи отправляются только выбранному AI-провайдеру для аутентификации, но не издателю. При импорте ключа по Wi-Fi гарнитура временно принимает файл в той же сети; передача не зашифрована, поэтому используйте только доверенную частную сеть.
  • Диагностика. Приложения создают ограниченный технический журнал на устройстве — до 500 строк; при следующем запуске он начинается заново. В журнале могут быть текст вопроса или запроса эксперту; VrAI Virt также может записывать распознанный текст разговора и ответ AI. Записываются и сведения об ошибках и моделях. Значения ключей в журнал не записываются. Журналы автоматически издателю не отправляются.
  • Изображения в галерее. Если сохранение изображений включено, приложения используют общую галерею Quest и перезаписывают собственный предыдущий файл: Pictures/VrAI/VrAI_Pass.jpg или Pictures/VrAI/VrAI_Virt.jpg. Эти файлы остаются в галерее после очистки личных данных приложения; удалите их отдельно в галерее.
  • Сетевые данные. Устройство напрямую связывается с AI-провайдером и передает обычные данные соединения, например IP-адрес, идентификаторы API-аккаунта, объем запросов и сведения об ошибках. По вашему запросу приложения также могут напрямую обращаться к каталогам моделей AI-провайдеров для обновления списка моделей.

Цели обработки и получатели

Данные обрабатываются только для выбранной функции: разговора, анализа изображения, распознавания речи, перевода, синтеза речи или ответа эксперта. В зависимости от выбранной модели и функции запросы отправляются непосредственно с гарнитуры в Google Gemini API, OpenAI API, Anthropic API или, при выборе Qwen, в API Alibaba Cloud Model Studio. Издатель не использует промежуточный сервер, получающий аудио, изображения или содержание переписки приложения.

Указанные провайдеры самостоятельно управляют своими сервисами и условиями: условия Gemini API и обработка данных Google, контроль данных OpenAI API, срок хранения данных Anthropic API, конфиденциальность Alibaba Cloud Model Studio. Сроки хранения, проверка и использование зависят от сервиса провайдера, аккаунта, статуса оплаты и включенных функций и могут меняться. Перед отправкой конфиденциальных данных ознакомьтесь с условиями провайдера. Использование AI может оплачиваться через ваш API-аккаунт.

Приложения не используют облако издателя для хранения переписки. Издатель не получает ключи, вопросы, изображения или аудио через сервер приложения. Выбранный AI-провайдер получает только запросы, необходимые для выбранной функции, и сетевые метаданные.
