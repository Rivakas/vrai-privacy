Pagalba dėl programų: rivakas@gmail.com

Laiške nurodykite programą (Pass arba Virt), Quest modelį, ką darėte ir kokį klaidos tekstą matėte. Nesiųskite API raktų, slaptažodžių ar asmeninių duomenų.

Pradžia

  • Abi programos veikia atskirai. „Pass“ yra imersinis asistentas; „Virt“ yra 2D langas, kurį galima laikyti šalia kitų programų.
  • AI paslaugų API raktai į pirkinį neįtraukti. Savo raktą įveskite programos nustatymuose. Jį galima įklijuoti, pasirinkti iš vienos eilutės .txt failo arba įkelti per Wi-Fi tame pačiame tinkle. Už API naudojimą atsiskaitoma su pasirinktu AI tiekėju atskirai.
  • Programų viduje atidarykite „Pagalba“, jei reikia išsamių valdiklių ir nustatymų paaiškinimų.

VrAI Pass

„Pass“ skirta Quest 3 ir Quest 3S. Kairiojo pultelio „Menu“ atidaro nustatymus. Dešiniojo „A“ naudojamas kalbėjimui paspaudus, „B“ padaro nuotrauką. Kai prašoma, suteikite mikrofono ir kameros leidimus.

VrAI Virt

2D lango mygtukus spauskite pultelio spinduliu ir gaiduku; fiziniai X, Y, A ir B mygtukai šio lango nevaldo. Norėdami versti kitos programos garsą, „Horizon OS“ įjunkite „Seamless Multitasking“, pasirinkite „Audio interpreter“ ir patvirtinkite sistemos garso fiksavimo langą. „Gemini“ reikia „Gemini“ API rakto; „Qwen“ reikia atskiro API rakto ir „Workspace ID“.

Privatumo politika

English

App support: rivakas@gmail.com

Include the app name (Pass or Virt), Quest model, steps leading to the problem, and the exact error message. Do not send API keys, passwords, or personal data.

Getting started

  • The apps work independently. Pass is an immersive assistant; Virt is a 2D window that can stay beside other apps.
  • AI provider API keys are not included with the purchase. Enter your own key in Settings. You can paste it, select a one-line .txt file, or transfer it over Wi-Fi on the same network. AI provider usage is billed separately by that provider.
  • Open Help inside either app for detailed controls and settings.

VrAI Pass

Pass is for Quest 3 and Quest 3S. The left controller Menu button opens Settings. The right A button is used for push-to-talk; B takes a photo. Grant microphone and camera permissions when prompted.

VrAI Virt

Use the controller ray and trigger to press buttons in the 2D window; the physical X, Y, A and B buttons do not control it. To translate another app's audio, enable Seamless Multitasking in Horizon OS, choose Audio interpreter, and approve the system audio capture prompt. Gemini needs a Gemini API key. Qwen needs its own API key and Workspace ID.

Начало работы

  • Приложения работают независимо. Pass — иммерсивный ассистент; Virt — 2D-окно рядом с другими приложениями.
  • API-ключи поставщиков ИИ не входят в покупку. Введите свой ключ в настройках. Его можно вставить, выбрать из однострочного файла .txt или передать по Wi-Fi в той же сети. Использование API оплачивается поставщику ИИ отдельно.
  • Откройте раздел помощи внутри каждого приложения для подробного описания кнопок и настроек.

VrAI Pass

Pass предназначен для Quest 3 и Quest 3S. Кнопка Menu на левом контроллере открывает настройки. Кнопка A на правом контроллере используется для разговора при нажатии, B делает снимок. Разрешите доступ к микрофону и камере при запросе.

VrAI Virt

Нажимайте кнопки 2D-окна лучом контроллера и курком; физические кнопки X, Y, A и B этим окном не управляют. Для перевода звука другого приложения включите Seamless Multitasking в Horizon OS, выберите Audio interpreter и подтвердите системный запрос на захват звука. Для Gemini нужен ключ Gemini API; для Qwen — отдельный API-ключ и Workspace ID.
